A minute-by-minute quantile forecaster for every market of Polymarket's "Next CEO of NVIDIA?" event: per-market robust realised volatility with separate up/down estimates, a saturating horizon spread, and fattened outer quantiles, fitted on the event's own public price history.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
